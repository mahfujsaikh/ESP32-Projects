# ESP32 Projects

A collection of my ESP32-based electronics, IoT, sensor, display, audio and embedded-system projects.

This repository contains both small experiments and practical projects developed while learning **embedded systems, electronics, IoT and ESP32 development**.

---

## 🛠️ Platforms & Tools

- ESP32
- ESP32-S3
- ESP32-C3
- ESP32-C6
- Arduino IDE
- ESP-IDF
- VS Code
- Git & GitHub

---

## 📂 Projects

### 💡 LED & GPIO

Experiments with GPIO, LEDs, RGB LEDs and basic digital control.

### 📡 Sensors

Experiments with different sensors and modules:

- MPU6050 — Accelerometer & Gyroscope
- MAX30102 — Pulse Oximeter / Heart Rate Sensor
- VL53L0X — Time-of-Flight Distance Sensor
- LDR — Light Sensor
- PIR — Motion Sensor

### 📟 Displays

Experiments with:

- ST7735 TFT
- ST7789 TFT
- OLED displays
- MAX7219 LED Matrix

### 🔊 Audio

ESP32 audio experiments using:

- INMP441 microphone
- MAX98357A I2S amplifier
- PAM8403 amplifier
- I2S communication

### 🌐 IoT & Web Control

Projects involving:

- Wi-Fi
- ESP32 Web Servers
- Blynk
- Relay control
- Remote device control
